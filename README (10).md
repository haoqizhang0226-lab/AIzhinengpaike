# 智能排课 V3.0 完整站点

此目录可直接用于 GitHub Pages。入口是根目录 `index.html`，打开后先显示可交互业务流程图。点击流程卡片可在右侧查看详细内容；顶部按钮和详情中的链接可进入原型、算法方案、AI 配置及教师推荐流程。

## 部署方法

1. 解压 ZIP，上传**解压后的全部内容**到 GitHub 仓库根目录。用本包的 `index.html` 覆盖仓库原有首页。不要仅上传 ZIP，也不要将整个外层文件夹作为子目录上传。
2. 在仓库 **Settings → Pages** 中选择发布分支及 `/ (root)` 目录。
3. 发布后访问仓库的 GitHub Pages 地址。首页应显示“智能排课V3.0：AI算法排课”流程图。

“查看原型”跳转到独立的 `prototype-v3-20261105-final/` 目录，避免与先前部署的原型路径混淆。原型内包含销售工作台与教务工作台切换。
