# 智能排课 V3.2：从发起到处理的完整原型

打开本目录的 `index.html`，从销售工作台开始体验。页面顶部的“销售工作台”“教务工作台”两个标签可切换；打开某张新排课单时带入该单，从列表直接切换时带入最新提交的排课单及顾问补充。本目录独立于 V3.1 存档。

销售工作台左侧“售前咨单”提供客户姓名或编号与发起时间筛选。提交后演示 AI 分析与待确认补充，通过后在销售端选择老师并生成按周切换的预排课表；已完成咨单的查看页展示咨单信息与预排课表。演示数据保存在当前浏览器本地。

## 体验路径

1. 点击“发起排课单”，查看预填的申请信息，点击“申请”返回列表并打开 AI 分析抽屉。
2. 分析中显示整页加载；返回待确认问题后，左侧查看排课单信息，右侧一次性补充说明。超过 60 秒时可点击“稍后查看”，待结果返回后从右下角提示进入。
3. 点击列表中的排课单，在详情页的“要求备注”下方查看“补充要求”卡片，其中展示补充时间和内容。
4. 切换至顶部“教务工作台”标签，进入本目录 `教务端/`。课程、日期、原排课要求和补充说明会随单带入。
5. 教务端排课单详情展示顾问补充内容。点击“智能排课”后，已有可用策略就进入“确认排课策略”；没有可用策略就先进入“补充排课要求”，重新分析成功后确认策略。策略页可查看原要求与补充内容、编辑策略，并逐科指定授课老师。确认后生成学生计划并进入“选择排课老师”；选师页展示老师要求、学生计划和候选老师。选完老师后继续联合排课。点击顶部“销售工作台”标签可返回该排课单详情。

顾问端预检、教务端初始策略、教师日程和正式课节均为原型示例数据。教务端会按顾问提交的课程生成每周 1—2 节的初始策略，可在“编辑排课策略”中调整；页面不连接真实大模型或业务系统。顾问端新建排课单和回复优先保存在浏览器本地。跨页面传递数据也写入页面地址，便于本地静态预览。
