# 智能排课 V3.2 GitHub Pages 部署文件

将本目录内的全部文件和 `教务端` 文件夹复制到 GitHub 仓库主分支的根目录。
不要上传外层文件夹或 ZIP 文件本身；仓库根目录应直接看到 `index.html` 和 `.nojekyll`。
在仓库 Settings → Pages 中选择 Deploy from a branch、main、/(root)。
发布入口为仓库 GitHub Pages 地址下的 `index.html`。

顶部标签依次为销售工作台、教务工作台、班主任工作台、教学工作台、钉钉工作台、企微侧边栏、业务流程、排课算法。
所有标签和教务端内部返回链接均使用相对路径，适用于带仓库名前缀的 GitHub Pages 地址。
班主任工作台目前仍是原型占位页。原型数据保存在浏览器本地，站点为静态页面。
