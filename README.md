# 智能排课 V3.0：从发起到处理的完整原型

打开本目录的 `index.html`，从销售工作台开始体验。页面顶部的“销售工作台”“教务工作台”两个标签可切换；打开某张新排课单时带入该单，从列表直接切换时带入最新提交的排课单及顾问补充。此目录独立于“智能排课V3.0方案一”存档和原顾问端演示页面。

## 体验路径

1. 点击“发起排课单”，查看预填的申请信息，点击“申请”返回列表并打开 AI 分析抽屉。
2. 分析中显示整页加载；返回待确认问题后，左侧查看排课单信息，右侧一次性补充说明。超过 60 秒时可点击“稍后查看”，待结果返回后从右下角提示进入。
3. 点击列表中的排课单，详情底部可查看“AI检测结果”；需补充时可打开对应抽屉。补充后显示检测通过，并在“补充排课要求”卡片中查看补充时间和内容。
4. 点击详情抽屉中的“转入教务处理”，进入本目录 `教务端/` 内单独复制的 V3.0 方案一原型。课程、日期、原排课要求和补充说明会随单带入。
5. 教务端排课单详情展示顾问预检后补充内容。点击“智能排课”直接打开确认排课策略；点击页顶“查看排课要求”可查看原要求、顾问补充和课程日期等完整信息。随后可编辑策略、选择老师并生成课节。点击顶部“销售工作台”标签可返回该排课单详情。

顾问端预检、教务端初始策略、教师日程和正式课节均为原型示例数据。教务端会按顾问提交的课程生成每周 1—2 节的初始策略，可在“编辑排课策略”中调整；页面不连接真实大模型或业务系统。顾问端新建排课单和回复优先保存在浏览器本地。跨页面传递数据也写入页面地址，便于本地静态预览。
